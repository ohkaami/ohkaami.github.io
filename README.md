# Camila Teodoro — GitHub Pages

Portfólio pessoal em HTML/CSS, com estética cyberpunk/arcade, fundo preto quadriculado e neon lavanda, rosa e azul.

## Publicar no GitHub Pages

1. Crie um repositório chamado `ohkaami.github.io` na sua conta do GitHub.
2. Envie `index.html` e `style.css` para a raiz do repositório.
3. Vá em **Settings → Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Escolha a branch `main` e a pasta `/ (root)`.
6. Salve e aguarde a publicação.

O endereço será:
`https://ohkaami.github.io/`

> Antes de publicar, confira os dados de contato e as certificações.
